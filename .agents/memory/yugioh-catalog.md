---
name: Yu-Gi-Oh catalog ambiguity
description: Live catalog identity pitfalls for exact-print market comparisons.
---

Do not assume a Yu-Gi-Oh set abbreviation or printed card code uniquely identifies a market-price product.

**Why:** Live TCGCSV inspection found distinct original/reprint groups sharing abbreviations such as RP02, and seven rarities sharing RA01-EN008. Choosing the first match can compare materially different products.

**How to apply:** Preserve candidate groups and distinguish print run, edition, and rarity before pricing; omit a comparison when identity remains ambiguous.
